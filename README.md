# StackPort

StackPort는 로컬 우선 원격 접속·데이터베이스 작업 공간을 만드는 프로젝트입니다. 전체 요구사항은 [기능 명세서](StackPort_Functional_Spec_KO.md)에 있습니다. 현재 코드는 초기 구현이며 명세 전체가 완성된 제품이 아닙니다.

## 현재 사용 가능한 기능

- 로컬 프로젝트 생성·이름 변경·삭제와 프로젝트별 SQLite 연결 정의 저장
- 기존 SQLite 파일에서 테이블과 뷰, 열·키·인덱스·생성 SQL을 읽기 전용으로 탐색
- 단일 읽기 전용 SQL 실행, 결과 100행씩 조회, NULL과 BLOB 구분 표시
- 지원되는 SQLite 테이블의 단일 셀을 미리보기·명시적 승인 후 변경하고 행 전체의 동시 수정과 저장 결과 검증
- 연결별 SQL 초안을 앱 실행 중 메모리에 보관하고, 프로젝트·연결 삭제 전 영향 확인
- SQLite 온라인 백업 API로 전체 DB 스냅샷을 만들고 무결성 검사. 기존 파일은 덮어쓰지 않음
- 프로젝트·연결 변경, SQLite 셀 변경과 백업의 로컬 작업 기록 조회

삭제 명령은 저장된 연결 정의만 삭제하며 데이터베이스 파일을 삭제하지 않습니다. 파일은 미리 존재해야 합니다. SQL 편집기는 읽기 전용으로, 하나의 결과를 반환하는 쿼리만 실행합니다. 바인딩 매개변수, SQL 쓰기, DDL, PRAGMA 및 데이터베이스 첨부는 아직 지원하지 않습니다. 조회는 최대 10초 동안 실행되며 셀의 긴 텍스트는 앞 4,096자만 표시합니다. 데이터 순서가 중요하면 SQL에 `ORDER BY`를 지정하세요. 쿼리 초안은 앱 종료나 비정상 종료 후 복구되지 않습니다.

행 편집은 원본 SQLite 파일을 실제로 변경합니다. 기본 키가 있고 트리거·생성 열이 없는 일반 테이블에서 기본 키·고유 키가 아닌 짧은 텍스트, 정수, 실수 또는 NULL 셀 하나를 변경할 수 있습니다. BLOB, 긴 값, NULL/BLOB 기본 키와 가상 테이블은 편집할 수 없습니다. 미리보기 이후 행이 바뀌거나 제약·형식 검증이 실패하면 변경을 중단합니다. `PROD` 연결은 `PROD`를 직접 입력해야 합니다. 저장 후 자동 되돌리기는 없으므로 필요하면 먼저 백업하세요.

백업 파일은 암호화되지 않으며 저장 폴더의 권한으로 보호해야 합니다. 앱이 수행하는 SQLite 무결성 검사는 별도 환경에 복원해 실제 데이터를 확인하는 테스트와 다릅니다. 백업 기능은 원본 DB의 파일 형식과 전체 데이터에 한정되며 예약, 암호화, 자동 복원은 아직 제공하지 않습니다.

SSH, 터미널, 다른 DB 엔진, 행 추가·삭제와 일괄 편집, 협업, AI, 브라우저 게이트웨이 및 설치·업데이트 패키지 등 나머지 기능은 아직 제공되지 않습니다. 브라우저에서는 로컬 파일 연결을 제공하지 않습니다. 요구사항별 현재 상태는 [추적표](docs/requirements.csv), 구현 경계와 검증 범위는 [구현 현황](docs/IMPLEMENTATION.md)을 참고하세요.

## 개발 실행

Windows에서 Node.js 20.19 이상 또는 22.12 이상, Rust, C++ 빌드 도구, WebView2가 필요합니다. macOS와 Linux는 아직 검증하지 않았습니다.

```powershell
npm ci
npm run dev
```

다른 터미널에서 다음을 실행합니다.

```powershell
cargo run --manifest-path src-tauri/Cargo.toml
```

프런트엔드를 빌드하고 내장 리소스로 데스크톱 바이너리를 만들려면 다음을 실행합니다. 서명된 배포 패키지는 아직 구성하지 않았습니다.

```powershell
npm run build
cargo build --release --features custom-protocol --manifest-path src-tauri/Cargo.toml
```

메타데이터는 기본적으로 OS의 앱 데이터 디렉터리에 있는 `workspace.sqlite`에 저장됩니다. 별도의 위치를 사용하려면 실행 전에 `STACKPORT_DATA_DIR` 환경 변수를 지정할 수 있습니다. 버전 1 작업 공간은 이관 전에 같은 폴더에 무결성을 확인한 백업을 남깁니다. 연결 정의와 작업 기록이 포함된 폴더와 백업의 접근 권한은 사용자가 관리해야 합니다. 비밀번호나 개인키를 저장하는 기능은 없습니다.

```powershell
cargo test --manifest-path crates/stackport-core/Cargo.toml
npm run build
cargo check --manifest-path src-tauri/Cargo.toml
```
